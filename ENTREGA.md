## Demostración de hasta tres minutos

- 0:00–0:30: objetivo y API utilizada.
- 0:30–1:15: buscar una ciudad, elegir ubicación y explicar el pronóstico.
- 1:15–1:45: mostrar favoritos y un error sin conexión.
- 1:45–2:30: explicar request(), fetch, estado HTTP y AbortController.
- 2:30–3:00: mostrar README, uso de IA, limitaciones y mejora personal.

Antes de entregar, completa el contacto, revisa la bitácora y asegúrate de poder explicar cada parte del código.
